AgentDossier {{ .Chart.AppVersion }} is deploying as release {{ .Release.Name }}.

1. Wait for the pod:   kubectl -n {{ .Release.Namespace }} rollout status deploy/{{ include "agentdossier.fullname" . }}
2. Reach it locally:   kubectl -n {{ .Release.Namespace }} port-forward svc/{{ include "agentdossier.fullname" . }} 8080:{{ .Values.service.port }}
3. Check status:       curl -s -H "Authorization: Bearer $AGENTDOSSIER_ADMIN_TOKEN" http://localhost:8080/api/status
4. First scan:         curl -s -X POST -H "Authorization: Bearer $AGENTDOSSIER_ADMIN_TOKEN" http://localhost:8080/api/scan
   (or AGENTDOSSIER_SCAN_ON_START=1 runs one on the first request)
5. Notifications:      curl -s -X POST -H "Authorization: Bearer $AGENTDOSSIER_ADMIN_TOKEN" http://localhost:8080/api/notify/test

The scanner only reaches the CIDRs and hosts listed under scope/targets in enterprise.json;
