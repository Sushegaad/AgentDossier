# Seed workbook

snapshot 25 Sep 2026, compiled by Hemant Naik from public sources (see the
workbook's Methodology and Source Catalog sheets). 12 domain sheets × 100

`agentdossier seed-check` recomputes every domain score from its components
with `config/scoring.json` and fails if any differs by more than 0.1.
